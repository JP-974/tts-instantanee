# tts-instantanee

Page web de synthèse vocale instantanée, autonome et sans dépendance (Web Speech API).

## Utilisation

Ouvrir `index.html` dans un navigateur (Chrome, Edge ou Firefox). Écrire ou coller du
texte (Ctrl+V) dans le champ : la lecture démarre automatiquement.

## Fichiers

- `index.html` — structure de la page
- `style.css` — mise en forme
- `app.js` — lecture automatique, contrôles (lire / pause / arrêter, voix, vitesse, hauteur)
